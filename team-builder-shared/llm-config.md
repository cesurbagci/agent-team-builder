# llm-config.md — Model ve Effort Yapılandırması Sözleşmesi

> Paylaşılan referans. **Bu dosya sözleşmedir:** dosya biçimi, çözümleme kuralı,
> ekosisteme yazım, doğrulama ve katalog komutları. **Prosedürü anlatmaz** — kullanıcıya ne
> sorulacağı ve hangi sırayla yapılacağı `team-builder-models` skill'ine aittir. Aynı
> kuralı iki yerde anlatmak drift üretir.

## Dosyalar

| Dosya | Git | Rol |
|---|---|---|
| `.agent-source/llm.json` | Commit edilir | Takımın seçimi |
| `.agent-source/llm.local.json` | Git'e girmez | Yalnız bu makine; ortak dosyayı ezer |

İkisi de isteğe bağlıdır ve şekilleri aynıdır:

```json
{
  "defaults": { "claude": { "model": "sonnet" } },
  "agents": {
    "architect": {
      "claude": { "model": "claude-opus-5-5", "effort": "high" },
      "codex":  { "model": "gpt-5.6-terra", "effort": "high" }
    }
  }
}
```

- Kök anahtarlar `defaults` ve `agents`; ekosistemler `claude`, `codex`, `opencode`; girdi
  alanları `model` ve `effort`. Üç liste de **kapalıdır**.
- `agents` altındaki adlar manifest'teki agent adlarıdır.

## Çözümleme

Her agent ve ekosistem için katmanlar sırayla aranır:

1. yerel `agents[<agent>][<ekosistem>]`
2. yerel `defaults[<ekosistem>]`
3. ortak `agents[<agent>][<ekosistem>]`
4. ortak `defaults[<ekosistem>]`

- **model:** `model` alanı olan ilk katman.
- **effort:** `effort` alanı olan ilk katman — ama model bir katmandan geldiyse yalnız o
  katman ve **üstündekiler** aranır. Effort'un geçerliliği modele bağlıdır; alttaki effort
  başka bir model için seçilmiştir.
- Bulunmayan alan için **satır yazılmaz**; ekosistemin kendi varsayılanı geçerli olur.

İki dosya da yoksa her şey boş çözümlenir; bu geçerli bir durumdur. Kod: `llm-config.mjs`
(`resolveModelSettings`).

## Ekosisteme yazım

| Hedef dosya | Model | Effort |
|---|---|---|
| `.claude/agents/<ad>.md` | frontmatter `model:` | frontmatter `effort:` |
| `.codex/agents/<ad>.toml` | `model = "…"` | `model_reasoning_effort = "…"` |
| `.opencode/agents/<ad>.md` | frontmatter `model:` | frontmatter `reasoningEffort:` |

- Bir ekosistemin girdisi **yalnız** o ekosistemin dosyasına yansır.
- Claude dosyası kaynak rol dosyasının kopyasıdır; model ve effort frontmatter'ın sonuna
  eklenir. Kaynak rol dosyası `model:` ya da `effort:` taşırsa sync **durur**.
- Frontmatter değerleri belgelenen biçimde tırnaksız yazılır (`model: sonnet`); YAML
  sözdizimi sayılabilecek bir şeyle başlayan değer tırnaklanır.
- OpenCode `reasoningEffort`'u sağlayıcıya olduğu gibi aktarır (`opencode debug agent <ad>`
  onu `options` altında gösterir); anlamı sağlayıcıya bağlıdır.
- OpenCode'da model verilmemişse birincil ajan genel modeli, alt ajan onu çağıranın
  modelini kullanır. Kodda sabit bir yedek harita **yoktur**.

## Git'e girmeyen çıktı

Ajan dosyaları çözümlenmiş modeli taşır ve o model bu makinenin yerel dosyasından
gelebilir. Bu yüzden şunlar **git'e girmez**:

- `.agent-source/generated-files.json` (defter)
- `.agent-source/llm.local.json`
- her agent için etkin hedeflerine göre `.claude/agents/<ad>.md`,
  `.codex/agents/<ad>.toml`, `.opencode/agents/<ad>.md`

Sync bunları `.gitignore`'da işaretli bir blokta tutar:

```gitignore
# >>> team-builder (generated by sync — do not edit this block)
/.agent-source/generated-files.json
/.agent-source/llm.local.json
/.claude/agents/architect.md
# <<< team-builder
```

- **Dizin değil, dosya yolu:** kullanıcının aynı dizinlere elle yazdığı agent'lar git'te
  kalmalıdır.
- Liste yalnız manifest'ten hesaplanır. Yerel dosya içeriği değiştirir, dosya kümesini
  değiştirmez; blok **her makinede aynıdır**.
- Bloğun dışına dokunulmaz. Başlangıç işareti olup bitiş işareti yoksa sync **durur**.
- `.codex/agent-definitions/` model taşımaz; git'te kalır.
- `--check`: eksik yerel çıktı **kayma değildir** — CI'da ve taze klonda hiç yoktur; bilgi
  satırıyla söylenir. Var olup farklı olan yerel çıktı kaymadır.

## Doğrulama

`validate-llm.mjs` — **biçim, üyelik değil.** Claude sağlayıcıya özgü kimlikleri de kabul
ediyor: Bedrock'ta inference profile ARN'si, Google'da `claude-sonnet-4-5@20250929`,
Foundry'de dağıtım adı, ağ geçidinin arkasında serbest metin, ayrıca `opus[1m]` gibi son
ekler. Bir model listesi, hatta `claude-` önek kuralı bile bunları reddederdi.

| Kural | Ortak dosya | Yerel dosya |
|---|---|---|
| Kapalı anahtar listeleri | Hata | Hata |
| Değer boş olmayan, boşluksuz metin | Hata | Hata |
| OpenCode modeli `sağlayıcı/model` | Hata | Hata |
| Agent manifest'te var | Hata | Uyarı |
| Ekosistem agent'ın etkin hedeflerinde | Hata | Uyarı |
| `claude-<aile>-<n>.<n>` biçiminde noktalı sürüm | Uyarı | Uyarı |

Yerel dosya manifest konusunda hoşgörülüdür: takım arkadaşı bir agent'ı kaldırdığında benim
eski yerel girdim benim sync'imi durdurmamalı.

Manifest'teki `model`, `model_reasoning_effort` ve `opencode_model` **eski alanlardır**;
`validate-manifest.mjs` onları göç mesajıyla reddeder.

## Katalog

`model-catalogs.mjs` — çözümlenmiş değerleri bu makinenin CLI'larının bildirdiğiyle
karşılaştırır. **Yalnız uyarır**, `--check` modunda da; kataloglar makineye ve hesaba göre
değişir, CI'da yoktur.

| Ekosistem | Komut | Verdiği |
|---|---|---|
| Codex | `codex debug models` | JSON; her model için `slug`, `visibility` (`list`/`hide`), `default_reasoning_level`, `supported_reasoning_levels`, `upgrade` (`model`, `retirement_at`, `migration_markdown`) |
| OpenCode | `opencode models` | Satır başına `sağlayıcı/model` — yalnız bu makinede yapılandırılmış sağlayıcılar |
| Claude | — | Katalog komutu yok |

- Uyarı durumları: Codex'te model katalogda yok, effort modelin desteklediklerinde yok,
  `upgrade` dolu (emeklilik tarihi ve yerine önerilen model); OpenCode'da model listede yok.
- Gizli (`hide`) modeller katalogda sayılır.
- Modeli çözümlenmemiş bir girdi denetlenmez: effort, hangi modelin çalışacağı (ekosistemin
  varsayılanı) bilinmeden değerlendirilemez.
- Her komut 10 saniye sınırla çalışır (ölçülen 1–2 s). CLI yoksa kontrol **sessizce**
  atlanır; CLI var ama hata verdi, zaman aşımına uğradı ya da okunamayan bir şey bastıysa
  **tek bilgi satırı** yazılır.

## Taşınabilirlik

Ortak dosya "bu makinede ne varsa" değil, "herkeste ne varsa"dır:

- Claude'da takma ad (`opus`, `sonnet`, `haiku`, `fable`) — herkeste var ve hep en yeni
  sürümü gösterir.
- Codex'te yalnız katalogda `visibility: list` olan ve `upgrade` alanı boş modeller.
- OpenCode'da model adı sağlayıcıyı içerir; takımın ortak bir sağlayıcısı yoksa OpenCode
  ortak dosyaya girmez.

Yerel dosya yalnız **farkları** tutar.
